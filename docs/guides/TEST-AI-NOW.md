## 🔍 TROUBLESHOOTING

### Frontend doesn't load
- Check if it's running: http://localhost:5173
- Terminal should show: "VITE v5.4.20 ready in XXX ms"

### Backend not responding
- Check if it's running: http://localhost:8000/docs
- Terminal should show: "Application startup complete"

### "Advanced Analysis" button doesn't appear
- Make sure you filled out ALL required survey questions
- Check browser console (F12) for errors

### AI Mode shows "Service Unavailable"
- Check backend terminal for errors
- Verify GEMINI_API_KEY in `backend/.env`
- Try Local Mode to verify basic functionality

### No bilingual interpretation
- Check if you selected "AI Mode" (not "Local Mode")
- Wait 5-10 seconds (might be slower on first call)
- Check backend logs for Gemini API errors

### Charts don't render
- Try refreshing the page
- Check browser console for JavaScript errors
- Verify you have data from the survey

## 📊 WHAT TO LOOK FOR

### Thai Interpretation (ภาษาไทย)
Should contain Thai Unicode characters (ก-ฮ)
Example keywords:
- "ความสัมพันธ์" (relationship)
- "นัยสำคัญทางสถิติ" (statistically significant)
- "รสนิยมทางเพศ" (sexual orientation)
- "อัตลักษณ์ทางเพศ" (gender identity)

### English Interpretation
Should be clear, professional, suitable for research participants
Example keywords:
- "statistically significant"
- "relationship"
- "sexual orientation"
- "gender identity"
- "effect size"
- "p-value"

### Both Should Include:
- Clear explanation of statistical findings
- Appropriate tone (professional but accessible)
- No personal data or individual responses
- Context about what the results mean
- 200-800 characters in length

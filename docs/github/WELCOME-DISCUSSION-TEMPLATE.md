## 🎯 What is this project?

This tool helps individuals explore and understand sexual fluidity through:

- 📊 **Interactive Survey** - 20 thoughtfully designed questions
- 🤖 **AI-Powered Chatbot** - Get personalized insights in Thai or English
- 📈 **Advanced Analysis** - Statistical ANOVA with 10+ submissions
- 🌈 **Bilingual Support** - Full Thai/English language support
- 🔒 **Privacy First** - Zero data collection, completely anonymous
